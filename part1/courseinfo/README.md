# Course information - exercises 1.1-1.2

React and Vite application for Full Stack Open Part 1.

## Run

```sh
npm install
npm run dev
```

Use the local address printed by Vite. Validate with `npm run lint` and `npm run build`.

## Components

- `App` owns the course data and passes it down through props.
- `Header` renders the course name.
- `Content` renders three reusable `Part` components.
- `Part` renders one topic and its exercise count.
- `Total` adds the counts: 10 + 7 + 14 = 31.

The separate variables match exercises 1.1-1.2. Objects and arrays are introduced in the following steps.

Prepared with AI assistance for explanation and implementation. Review the components and try changing a count to see both its row and the total update.

Part 1 has not been submitted. The course information app continues in exercises 1.3-1.5, followed by the other Part 1 exercise sets.
